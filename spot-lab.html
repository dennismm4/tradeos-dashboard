Limitations before any live trades

There is no broker-side stop, order audit/reconciliation, live bid/ask quote, real funding or exchange permission verification. Intrabar path is ambiguous with OHLC data; backtesting uses conservative stop assumptions but cannot model gaps, liquidity or market impact accurately. Drawdown locks prevent new entries, not guaranteed maximum losses. Do not connect API keys or treat backtest performance as a live-trading forecast.
